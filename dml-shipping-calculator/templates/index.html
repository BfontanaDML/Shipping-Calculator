How to Get Shipping Prices
  1. Open the UPS website and sign in with the DML UPS login:
    User ID
    UPSMPDM
    Password
    Creation11
  2. Open Shipping → Calculate Shipping Cost.
  3. Select Cap America as the shipping origin.
  4. Enter the destination postal code, set the customs value to $1, and click Update.
  5. Enter every package from Step 2 (dimensions and weight), then click Update. If Step 2 lists multiple boxes, include all of them.
  6. Under How will you pay the shipping charges?, choose DML’s UPS account number from the Select a UPS Account Number dropdown, then click Update.
  7. Select the UPS service chosen in Step 1.
  8. Copy the discounted Total Cost for the complete shipment into Step 3.
